Sync équipe (dossier partagé)
Publie tes modifs dans un dossier partagé (kDrive, Drive monté, S3…) et récupère celles des autres — async, pas de temps réel. Nouveaux traits fusionnés automatiquement ; un même trait modifié des deux côtés devient une correction à Accepter/Rejeter (comme un calque de révision).

Contacts (P2P) — modèle uniquement, pas encore de transport réseau réel
Pour travailler sur le même fichier en direct avec quelqu'un à distance, sans passer par un dossier partagé. Chaque contact est identifié par une clé, jamais un compte — colle le code de quelqu'un pour l'ajouter, partage le tien pour qu'il fasse pareil. La synchro P2P en temps réel n'est pas encore branchée — c'est la gestion des contacts qui est prête, le transport réseau viendra dans une phase séparée.

Feedback (hors projet)
Notes posées via l'outil Comment → "Enregistrer comme feedback" — jamais dans le fichier projet. Les tiennes sont approuvées automatiquement ; celles récupérées d'un autre profil via le dossier partagé restent en attente jusqu'à ce que tu les approuves ici.
Feedback beta-testeurs (GitHub)
Chaque feedback envoyé depuis une app distribuée arrive comme Issue sur mysteropodes/strokemotion-feedback. Colle ton propre token GitHub personnel (fine-grained, scope "Issues" sur ce repo uniquement) pour pouvoir trier — il reste uniquement sur ta machine, jamais distribué.
Raccourcis clavier — outils
Cliquer une touche puis appuyer sur une nouvelle touche pour la réassigner. Les autres raccourcis (transport, undo/save…) ne sont pas encore modifiables ici. Import de profils (Animate, Blender…) : à venir.
