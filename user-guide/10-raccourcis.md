# 10. Raccourcis clavier

## Outils

| Touche | Outil |
|---|---|
| V | Sélection |
| A | Sous-sélection (points & tangentes) |
| M | Sélection Fond/Trait |
| B | Pinceau |
| P | Plume |
| N | Pinceau de remplissage |
| U | Ligne |
| R | Rectangle |
| L | Ellipse |
| E | Gomme |
| G | Pot de peinture |
| I | Pipette |
| C | Commentaire |
| H ou Espace | Main (déplacer la vue) |
| Z | Zoom (Alt+clic pour dézoomer) |
| X | Échanger les couleurs de trait et de fond |
| Q (maintenir) | Menu radial d'outils |
| R (maintenir) | Rouleau d'animateur |
| M (maintenir, en dessin) | Miroir de contrôle |

## Timeline et frames

| Touche | Action |
|---|---|
| F5 | Insérer une frame |
| F6 | Insérer une keyframe |
| F7 | Insérer une frame vide |
| T | Tween (interpolation automatique) |
| D | Dupliquer la frame/plage |
| F | Flip (retournement) |
| Entrée | Lecture / Stop |
| O | Onion skin on/off |

## Divers

| Touche | Action |
|---|---|
| ⌘S | Enregistrer |
| Alt + glisser (n'importe quel outil) | Rotation du canevas |

Cette liste est extraite des info-bulles de l'interface — clic-droit ou survol prolongé d'un
bouton dans Nemo affiche systématiquement son raccourci s'il en a un.

## Personnaliser les raccourcis d'outils

**Réglages → Raccourcis** permet de réassigner les raccourcis des **outils** listés ci-dessus
(cliquer une touche affichée, puis appuyer sur la nouvelle) — voir
[Paramètres de l'application](13-parametres-app.md#raccourcis-clavier-personnalisables).

> ❌ **Pas encore disponible** : réassignation des raccourcis de transport (lecture, undo,
> sauvegarde…) et import de profils de raccourcis depuis d'autres logiciels.
